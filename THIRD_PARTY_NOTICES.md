## Controller image

The `simfleet-controller` image holds the manager binary built from this
repository on top of
[`gcr.io/distroless/static:nonroot`](https://github.com/GoogleContainerTools/distroless)
(Apache-2.0). The distroless base carries a few Debian packages, such as
`ca-certificates` and `tzdata`, whose licenses are in
`/usr/share/doc/<package>/copyright` in the image.

The manager binary statically links the Go modules listed in
[Go modules in the controller](#go-modules-in-the-controller), at the versions
[`go.mod`](go.mod) requires.

## Guest image

The `simfleet-node` image is a KubeVirt containerDisk built from
[`quay.io/containerdisks/ubuntu:24.04`](https://quay.io/repository/containerdisks/ubuntu),
the Ubuntu 24.04 cloud image, pinned by digest in
`images/simfleet-node/Makefile`. The build adds:

| Component | Version | License | Source |
| --- | --- | --- | --- |
| containerd, runc | Ubuntu 24.04 | Apache-2.0 | Ubuntu archive |
| qemu-guest-agent | Ubuntu 24.04 | GPL-2.0 | Ubuntu archive |
| apt-transport-https, ca-certificates, curl, gpg | Ubuntu 24.04 | Various | Ubuntu archive |
| kubelet, kubeadm, kubectl | 1.36.4 | Apache-2.0 | [pkgs.k8s.io](https://pkgs.k8s.io) |
| kubernetes-cni (CNI plugins), cri-tools | Latest in the v1.36 repository at build time | Apache-2.0 | [pkgs.k8s.io](https://pkgs.k8s.io) |
| mock-dpuagent | Commit in `hack/dpuagent/mock.ref` | Apache-2.0 | [NVIDIA/doca-platform](https://github.com/NVIDIA/doca-platform) |

Every Ubuntu package in the guest disk, including GPL-licensed ones such as
the Linux kernel, glibc and systemd, keeps its license in
`/usr/share/doc/<package>/copyright`. Their corresponding source is in the
Ubuntu archive and can be fetched with `apt-get source <package>`.

The mock-dpuagent binary statically links the Go modules listed in
[Go modules in mock-dpuagent](#go-modules-in-mock-dpuagent), at the versions
doca-platform's `go.mod` requires at that commit.
